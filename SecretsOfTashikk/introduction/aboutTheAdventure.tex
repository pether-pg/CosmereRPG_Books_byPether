\subsection{Campaign Themes}

This campaign is using themes as listed below. Use this list to determine if you are interested in running this kind of campaign. In the game, you can encounter themes of:
\begin{itemize}
	\item Secrets
	\item Trading secrets
	\item Stealing secrets
	\item ...and more secrets
\end{itemize}

\subsection{Campaign Setting}

The story is set in Tashikk, shortly after the arrival of the Everstorm and the events described in \bookED{}.

While the location is essential for the adventure an its themes, you can change the time of the events, eg. if you want to avoid \bookSA{} spoilers.
