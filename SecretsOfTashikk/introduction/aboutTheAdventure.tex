\section{About the Adventure}


\subsection{Campaign Themes}

This campaign is using themes as listed below. Use this list to determine if you are interested in running this kind of the campaign. In the game, you can encounter themes of:
\begin{itemize}
	\item Trading secrets
	\item Stealing secrets
	\item Protecting secrets
	\item ...and more secrets
\end{itemize}

\subsection{Campaign Setting}

The story is set in \locationYeddaw{}, a city in \locationTashikk{} princedom, shortly after the arrival of the Everstorm and the events described in \bookED{}.

While the location is essential for the adventure and its themes, you can change the time of the events, eg. if you want to avoid \bookSA{} spoilers.
