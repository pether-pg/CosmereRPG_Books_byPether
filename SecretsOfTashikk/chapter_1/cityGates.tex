\subsubsection{(Optional) Identification Form}

If you start this adventure without a party from the previous games, you might consider roleplay through the process of character creation, turning session zero into a more interactive experience.

Before proceeding to the next scene, allow \npcHauka{} to ask each character some questions about details she needs to fill in her paperwork. Let the players define the following at this point:

\begin{itemize}
	\item Name
	\item Appearance
	\item Occupation
	\item Spoken Languages
	\item Carried Weapons
	\item Special Talents
	\item Available Marks
\end{itemize}

After those are answered, you can proceed with filling the details, like exact attribute scores or total skill modifiers.

\reasonBox{
	Please note, this is not a suggested way to play this scenario as you should probably try to weave it with another module. However, I'm putting the idea here - in case you needed it and found it interesting.
}
